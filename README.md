# Árvore Genealógica (Foundry VTT)

Módulo para Foundry VTT v13+ que permite montar árvores genealógicas entre atores e visualizá-las em uma janela interativa.

## Instalação
Em *Instalar Módulo*, use o manifesto:

```
https://github.com/fernandowrpg/family-tree/releases/latest/download/module.json
```

## Uso
- Clique direito num ator → **Editar família** (pais, cônjuges, filhos, notas).
- Botão **Árvore Genealógica** no diretório de atores abre a árvore.
- Passe o mouse num nó para ver detalhes; clique para abrir a ficha.
